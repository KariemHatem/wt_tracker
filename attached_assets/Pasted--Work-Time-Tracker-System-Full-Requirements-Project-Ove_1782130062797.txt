# Work Time Tracker System - Full Requirements

## Project Overview

Build a modern, professional, responsive Work Time Tracking System using:

* Angular (latest version)
* PrimeNG
* Bootstrap
* SCSS
* Responsive Design
* Modern Futuristic UI/UX
* REST API
* Database Integration

The application should contain:

1. Employee/User Portal
2. Admin Dashboard
3. Authentication System
4. Reports & Analytics
5. Time Tracking Engine

---

# Authentication

## User Login

Users must log in using:

* Email
* Password

Features:

* Secure authentication
* JWT token-based authentication
* Remember Me option
* Logout functionality

## Admin Login

Only one admin account should have access to the dashboard.

Admin credentials should be configurable from the database or environment variables.

Admin permissions:

* View all users
* View all tracked hours
* View reports
* View login activity
* View analytics
* Manage users

Regular users cannot access the admin dashboard.

---

# User Management

Each user should have:

* Full Name
* Email
* Password
* Working Days Configuration
* Daily Working Hours Configuration
* Account Status

Default values:

* Daily working hours = 8 hours
* Working week = Sunday to Thursday

Business Rules:

* Friday and Saturday are NOT counted as working days by default.
* Users can customize their working days.
* Users can customize their daily target hours.
* If the user does not configure anything, use:

  * Sunday–Thursday
  * 8 hours/day

---

# Time Tracking System

## Start Work

User clicks:

"Start Work"

System should:

* Store start timestamp
* Start live timer
* Show elapsed time
* Continue counting even if page refreshes
* Continue counting after browser restart

## End Work

User clicks:

"End Work"

System should:

* Store end timestamp
* Calculate worked duration
* Save duration in database
